Panduan Akses, Sinkronisasi Antar User & Kustomisasi Mandiri

1. Apakah Data Antar User Saling Terhubung?

Secara Default (LocalStorage): Data tersimpan secara lokal di browser komputer masing-masing. Artinya, jika rekan tim membuka file ini di perangkat atau browser lain, data mereka masih terpisah.

Agar Terhubung Secara Real-Time (Cloud Sync): Anda dapat menghubungkan file HTML ini ke database cloud gratis (seperti Firebase Firestore) atau Google Apps Script (terhubung ke Google Sheets). Dengan cara ini, semua rekan tim yang membuka link yang sama akan melihat data yang tersinkron otomatis secara real-time.

2. Cara Kustomisasi Mandiri & Pengembangan

File ini dibuat menggunakan format Single-File HTML (HTML, CSS Tailwind, dan JavaScript bersatu). Anda dapat menyimpan file ini (misalnya sebagai `dashboard.html`), membukanya menggunakan text editor apa saja (seperti VS Code, Notepad++, atau Sublime Text), dan mengubah atau mengembangkan kodenya kapan saja.

3. Cara Akses Terbatas & Hosting

Untuk akses terbatas, Anda bisa mengunggah file ini ke server internal perusahaan (Intranet), GitLab Pages dengan password protection, atau layanan web hosting gratis (seperti Netlify / Vercel) dengan menyembunyikan tautannya dari publik.
